Chaque équipement peut porter une étiquette QR code ou un tag NFC : le scanner ouvre directement sa fiche, d'où l'on peut aussi enregistrer son retour. Les étiquettes s'impriment en planche depuis l'inventaire ; les tags se programment depuis la fiche.

## Imprimer des étiquettes

1. Menu, « Matériel ».
2. « Choisir les étiquettes QR code à imprimer », puis touchez les équipements à cocher (le choix reste quand vous changez de filtre).
3. « Imprimer … étiquette(s) » : la planche s'ouvre, prête à imprimer.
4. Pour un seul équipement : « Étiquette QR code » depuis sa fiche.

## Programmer un tag NFC

Sur un téléphone Android avec Chrome, NFC activé :

1. Ouvrez la fiche de l'équipement.
2. Laissez cochée « **Verrouiller le tag (définitif)** » : personne ne pourra plus l'effacer ni le réécrire.
3. « Programmer un tag NFC », puis approchez le tag du dos du téléphone sans bouger jusqu'au message de fin.
4. « Tag NFC programmé et verrouillé » : collez-le sur l'équipement (un tag spécial métal pour un bloc).

## Scanner une étiquette ou un tag

1. Dans « Matériel », « Scanner une étiquette ».
2. Visez le QR code, ou approchez le dos du téléphone du tag NFC (« Lire un tag NFC » la première fois) : la fiche s'ouvre toute seule.
3. Sur iPhone, prenez l'étiquette en photo : elle est lue par le serveur.
4. Étiquette illisible ? Saisissez la référence du club, ou son ancien numéro. Si plusieurs équipements ont eu le même ancien numéro, l'appli les cite : saisissez alors la référence actuelle.

## Bon à savoir

- L'appareil photo de n'importe quel téléphone ouvre aussi la fiche, sans passer par l'appli. De même pour un tag NFC : un iPhone le lit en approchant son haut, sans ouvrir le scanner.
- Le tag porte la même adresse que le QR code : il ne se reprogramme pas quand la référence change. C'est pourquoi on peut le verrouiller sans regret.
- Un tag verrouillé ne se réécrit plus jamais : décochez la case seulement pour un essai. Prenez des tags NTAG213, 215 ou 216.
- « Pas pu être verrouillé » : le tag marche quand même ; recommencez en le tenant immobile pour le verrouiller.
- Un tag vierge lu au scanner : l'appli le signale, programmez-le depuis la fiche.
- Corriger la référence d'un équipement ne demande pas de réimprimer son étiquette.
