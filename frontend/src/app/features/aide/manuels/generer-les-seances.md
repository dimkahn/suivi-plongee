Administration, « Séances », puis « Générer toutes les séances d'une saison » : choisissez les jours, la zone de vacances et la séance type ; l'aperçu montre ce qui sera créé avant de valider.

## Pas à pas

1. Administration, « Séances », puis « Générer toutes les séances d'une saison ».
2. Choisissez la zone de vacances scolaires.
3. Choisissez les jours de la semaine (le lundi est coché d'office).
4. Décrivez la séance : lieu, milieu, horaires…
5. Lisez l'aperçu, mois par mois : ce qui sera créé, ce qui est retiré et pourquoi.
6. Validez avec « Créer les … séances ».

## Bon à savoir

- Les vacances viennent du calendrier officiel de l'Éducation nationale : le serveur doit joindre internet. Source injoignable = refus explicite, jamais de dates devinées.
- Les jours fériés sont retirés d'office.
- Deux séances le même soir (piscine et fosse) ? Générez deux fois.
- Une séance exceptionnelle s'ajoute à la main (voir « Gérer les séances à la main »).
